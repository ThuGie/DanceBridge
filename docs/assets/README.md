# DanceBridge visual assets

The application icon was generated using the built-in OpenAI image generation tool. The PNG source retains transparency; the ICO contains 16, 24, 32, 48, 64, 128 and 256 pixel variants. The favicon is a 32 pixel PNG.

Prompt: A distinctive premium Windows app icon for DanceBridge: a miniature isometric dance pad with inset blue, coral, amber, mint and violet panels, dark center rest tile, graphite frame and brushed-metal frame. Edit: remove the USB connector, signal ribbon and bridge entirely; keep only the pad and recenter it. Refined arcade hardware design, controlled highlights, transparent background, no text.

Screenshots in ../screenshots are captures of the running Windows application, not generated UI mockups.

Small-size companion prompt: simplify the same pad for 16–48 pixel readability, with bold arrows, thick frame, near-front perspective, large separated tiles and no textures, screws, neon or reflections. ICO sizes up to 64 pixels use this companion artwork; 128 and 256 use the detailed pad.
